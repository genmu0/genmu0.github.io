Theory of Sensors

2026-11-14

This blog post works best in tandem with my prior post of low rank dynamical systems.

Intro

The prior discussion or low rank dynamical systems brings into question the issue of sensors. A sensor by definition senses a subset of the state space in time and space.

Assumptions

Let us pretend the universe obeys a simple stochastic cellular automaton on 3D. Each cell \(x\) is a cube in a 3D lattice. A cell’s future state has a \(0.5\) probability from the set \(\{0, 1\}\) and it has a \(0.5\) probability of copying one of its six neighbors. Let us pretend our universe is finite but still rather large, such as 1 million cells along each dimension.

The entire universe is governed by the stochastic process \(X_t\), and it start in the initial state \(X_0\) as an arrangement of multiple cells \(x\). The set of possible states is called the state space \(\mathcal X\), and it defines each possible universe configuration as \(\hat X_1,\hat X_2,...,\hat X_\theta\). We know that there are at most: $$\theta =2^{3 \cdot 1000000}$$ possible states.

We can claim that this finite universe behaves according to a finite Markov chain. We can model this Markov chain using a stochastic transition matrix \(P_{\theta \times\theta}\). To get the probability distribution of any state at time \(t\), we simply take the matrix power \(P^t\) and choose the row corresponding to the initial configuration for \(X_0\).

The First Reduction of Time

Our sensor \(S_t\) is a stochastic process too, and it is a mere subset of \(X_t\).1 It collects data at a rather slow rate of every \(\tau\) time steps where \(\tau \in \mathbb N > 1\). The best possible relation that it can figure out is using the low rank approximation formula: $$Q = K^{+} P^t K$$ in which \(K\) is the classification matrix. The sensor can at best model the universe using the class stochastic matrix \(Q = K^{+} P^\tau K\). Let us assume that we have the optimal classification matrix \(K_{n \times m}\) such that we always preserve the \(\tau\) largest eigenvalues of \(P\).

The Second Reduction of Space

Due to \(S\) being a subset of \(X\), we must define the unconditional probability distribution for each sensor cell \(x \in S\) given that we are ignorant of cells \(x \notin S\). If our sensor \(S\) has \(\eta\) cells, then we can at best describe our cellular automaton using \(R_{\eta \times \eta} \sim P_{\theta \times \theta}\). Our class stochastic matrix \(Q\) is now defined using this even smaller state space: $$Q = K^+ R^\tau K$$ The amount of information loss from our reduced measurement space and our reduced measurement frequency compound. I want to point out that this \(K\) is not computed: It is a byproduct of our sensor confusing similar states.2

The Third Reduction of Data

Worse still, our sensor can only collect data in the designated format such as \(2^{100}\). This is because our sensor needs to “waste space” on memory, data formatting, and transmitting. That means we must construct \(Q\) from this finite data. This data \(\Delta\) is the running average of binary relations from the subset of \(Q\). We then have a data state space \(\mathcal \Delta = (\Delta_1,...,\Delta_?)\) which is merely a count of binary relations. It is actually at this stage that how quickly and cleanly we can feed our raw data into storage that determines \(\tau\).

This leaves us with the formula: $$Q = K^+ \Delta^\tau K$$ Before we have even acquired our data to construct a modeling Markov chain \(Q\), we have experienced multiple absurd layers of reduction.

The Silver Lining

Thankfully, there is a limit to how badly our compression have reduced our ability to make predictions. This is because only corruptions to classification matrix \(K\) will matter. We can rewrite this formula: $$Q = K^+_3 \Delta^\tau K_3$$ according to the classification corruption from the sensor-to-memory: $$\iff Q = K^+_3 K^+_2 R^\tau K_2K_3$$ and according to the classification corruption from complete state space to reduced state space: $$\iff Q = K^+_3 K^+_2 K^+_1 P^\tau K_1 K_2 K_3$$ As long as our errors in measurement are within class or only between classes that strongly communicate, our ability to make predictions is sound.3

Closing Remarks

Here we have tackled the impossible task of defining how sensors work upon the assumption of the universe as a stochastic cellular automaton. Plato’s allegory of the cave was wrong in a way: With enough shadows, we can infer how reality works. We are restricted by the aperture of the lens, the quality of the brain, and the data we may collect, but it works nonetheless.

This means we have three parameters with which to improve our ability to make predictions:

  • Increase the size of the sensor \(S\)
  • Increase the signal-to-noise of the processed data \(\Delta\)
  • Increase the frequency of the sensor \(1 / \tau\) to write to storage
  • Increase the number of sensors to mimic increased size and frequency.

  1. We will pretend our sensor does not move. ↩︎

  2. We assume that our sensor state space \(S\) is only the “data collecting part”. ↩︎

  3. I want to point out that \(K_1\) is technically not a binary classification matrix since it compresses along unconditional probability, but the increased precision of a soft classifier washes away quickly. It also washes away exactly by means of classification, or optimal confusion, in most cases. ↩︎
